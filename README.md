# همکار (Hamkar) 🤝

یک اکستنشن **New Tab** برای گوگل کروم که تب جدید مرورگر را به یک فضای کاری تیمی تبدیل می‌کند: تیم بساز، همکارانت را دعوت کن، پروژه تعریف کن، تسک بسپار و داخل هر پروژه مثل تلگرام با هم چت کن.

> کلمه‌ی «همکار» یعنی coworker — این پروژه برای همکاریِ ساده و بی‌حاشیه ساخته شده.

## امکانات

- 🔐 **ورود با ایمیل (Magic Link)** — بدون رمز عبور؛ لینک ورود با [Resend](https://resend.com) ارسال می‌شود و نشست برای همیشه (تا خودت خارج نشوی) باقی می‌ماند.
- 👥 **تیم‌ها** — بساز، با کد دعوت یا دعوت ایمیلی عضو بگیر.
- 📁 **پروژه‌ها** — پروژه‌ی شخصی بساز یا آن را در تیم ثبت کن تا همه‌ی اعضا دسترسی داشته باشند.
- ✅ **تسک‌ها** — برای خودت یا دیگران تسک تعریف کن و تیک بزن.
- 💬 **چت هر پروژه** — محیط چت شبیه تلگرام با ارسال متن، عکس و فایل.
- 🛡️ **مدیای امن** — فایل‌های آپلودشده فقط برای اعضای همان پروژه قابل دریافت هستند؛ لینک مستقیم کار نمی‌کند.

## ساختار ریپو

```
hamkar-chrome/
├── extension/        اکستنشن کروم (Manifest V3 + Tailwind، بدون هیچ وابستگی خارجی)
│   ├── manifest.json
│   ├── newtab.html
│   └── js/           ماژول‌های جاوااسکریپت (auth, teams, projects, tasks, chat)
├── server/           بک‌اند PHP که روی هاست شما قرار می‌گیرد
│   ├── api/          همه‌ی اندپوینت‌ها (apps.webiro.ir/hamkar/api)
│   │   ├── index.php   ← فرانت‌کنترلر / روتر
│   │   ├── install.php ← ساخت خودکار جداول
│   │   ├── config.php  ← اطلاعات دیتابیس (گیت‌شده نیست؛ از config.example.php بسازید)
│   │   └── src/        کد ماژولار (Database, Auth, Mailer, Files, Controllers)
│   ├── media/        محل آپلود فایل‌ها (دسترسی مستقیم وب بسته است)
│   └── database/     اسکیمای MySQL برای مرور
├── scripts/
│   └── sync-ftp.sh   سینک فایل‌های سرور با FTP
└── docs/             راهنمای استقرار و مرجع API
```

## شروع سریع

### ۱) سرور

1. محتوای پوشه‌ی `server/` را روی مسیر `apps.webiro.ir/hamkar` آپلود کنید (یا با `scripts/sync-ftp.sh`).
2. `server/api/config.example.php` را به `config.php` تغییر نام دهید و اطلاعات دیتابیس MySQL و کلید API سرویس Resend را در آن بنویسید.
3. یک‌بار آدرس `https://apps.webiro.ir/hamkar/api/install.php` را در مرورگر باز کنید تا جداول ساخته شوند.
4. برای اطمینان از سلامت، `https://apps.webiro.ir/hamkar/api/` باید JSON سلامت برگرداند: `{"ok":true,"service":"hamkar-api"}`

جزئیات کامل در [docs/DEPLOY.md](docs/DEPLOY.md).

### ۲) اکستنشن

1. کروم را باز کنید و به `chrome://extensions` بروید.
2. حالت **Developer mode** را روشن کنید.
3. **Load unpacked** را بزنید و پوشه‌ی `extension/` این ریپو را انتخاب کنید.
4. یک تب جدید باز کنید — صفحه‌ی ورود با ایمیل را می‌بینید. 🎉

> اگر آدرس API شما چیز دیگری است، مقدار `API_BASE` در `extension/js/config.js` را عوض کنید.

## امنیت در یک نگاه

- توکن نشست به‌صورت هش‌شده در دیتابیس ذخیره می‌شود و در کوکی یا localStorage سایت‌ها نیست (در `chrome.storage` اکستنشن نگه‌داری می‌شود).
- همه‌ی کوئری‌ها با PDO و prepared statement اجرا می‌شوند.
- فایل‌های آپلودی با نام تصادفی بیرون از پوشه‌ی API ذخیره می‌شوند و `media/.htaccess` دسترسی مستقیم وب را کاملاً می‌بندد؛ دریافت فایل فقط از طریق اندپوینت احراز-هویت‌شده‌ی `/api/media/{id}` انجام می‌شود.
- لینک ورود (Magic Link) ۱۵ دقیقه اعتبار دارد و یک‌بارمصرف است.
